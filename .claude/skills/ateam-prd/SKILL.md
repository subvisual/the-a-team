# ateam-prd (stub)

**No-op placeholder.** The real PRD skill is authored later by a PM against
`CONTRACT.md`. This stub only exercises the orchestration wiring.

Given the feature directory `docs/features/<slug>/` and its `feature.json`:

1. Read `prompt` from `feature.json`.
2. Write `prd.md` in the feature directory:
   ```markdown
   # PRD (stub) — <slug>

   > Placeholder generated by the ateam-prd stub. Replace with the PM skill.

   **Prompt:** <prompt>

   TODO: problem, goals/non-goals, user stories, acceptance criteria, scope.
   ```
3. If the orchestrator passed revision notes, append them under a `## Revision notes` heading.
4. Read the current `feature.json`, set **only** `phases.prd.status = "complete"`,
   preserve every other field (including `attempts`), write it back. Save.

Do not touch any other manifest field or artifact. Be idempotent — overwrite
`prd.md` cleanly if re-invoked, never append duplicates.
