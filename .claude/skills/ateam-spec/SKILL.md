# ateam-spec (stub)

**No-op placeholder.** The real spec skill is authored later by a Designer against
`CONTRACT.md`. This stub only exercises the orchestration wiring.

Given the feature directory `docs/features/<slug>/` and its `feature.json`:

1. Read `prd.md`, `design.md`, and the target's design system (path from the
   `## A-Team Config` block in the target `CLAUDE.md`).
2. Write `spec.md` in the feature directory:
   ```markdown
   # Design spec (stub) — <slug>

   > Placeholder generated by the ateam-spec stub. Replace with the Design skill.

   TODO: component breakdown; every state (empty/loading/error/populated);
   responsive behavior; interactions and edge cases.

   ## Design-system mapping (required in the real skill)
   TODO: which existing design-system components and tokens each piece uses.
   No raw px/hex — reference tokens.
   ```
3. Read the current `feature.json`, set **only** `phases.spec.status = "complete"`,
   preserve every other field (including `attempts`), write it back. Save.

Do not touch any other manifest field or artifact. Be idempotent — overwrite
`spec.md` cleanly if re-invoked, never append duplicates.
