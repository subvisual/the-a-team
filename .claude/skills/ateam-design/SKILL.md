# ateam-design (stub)

**No-op placeholder.** The real design skill is authored later by a Designer
against `CONTRACT.md`. This stub only exercises the orchestration wiring.

Given the feature directory `docs/features/<slug>/` and its `feature.json`:

1. Read `prd.md`.
2. Write `design.md` in the feature directory:
   ```markdown
   # Design (stub) — <slug>

   > Placeholder generated by the ateam-design stub. Replace with the Design skill.

   TODO: IA, user flows, screen/layout direction, visual approach.
   ```
3. Create `docs/features/<slug>/lofi/` with a placeholder `README.md` (throwaway
   visual reference; the real skill produces a lo-fi prototype here).
4. If the orchestrator passed revision notes, append them under a `## Revision notes` heading.
5. Read the current `feature.json`, set **only** `phases.design.status = "complete"`,
   preserve every other field (including `attempts`), write it back. Save.

Do not touch any other manifest field or artifact. Be idempotent — overwrite
`design.md` cleanly if re-invoked, never append duplicates.
