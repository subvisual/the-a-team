# Designer — blueprint

[← Roster](../README.md#roster) · [Agent definition](../../.claude/agents/ateam-designer.md) · [Audit](../ISSUE.md) · [Authority map](../AUTHORITY-MAP.md) · [Runtime contract](../RUNTIME-CONTRACT.md) · [Skill integration](../SKILL-REVISIONS.md) · [Open questions](../OPEN-QUESTIONS.md)

**Status:** second pilot · **Lifecycle arms:** fresh per phase versus resumed design → spec

## Mandate

Own experience and visual-design craft from accepted definition through a dev-facing spec. Push back
when the requested surface does not serve the jobs; preserve incumbent visual truth in existing
products.

## Conducts and composes

- Conducts [`ateam-design`](../../.claude/skills/ateam-design/SKILL.md) and
  [`ateam-spec`](../../.claude/skills/ateam-spec/SKILL.md).
- Composes [`design-system`](../../.claude/skills/design-system/SKILL.md),
  [`build-lofi`](../../.claude/skills/build-lofi/SKILL.md), and relevant
  [`wireflow`](../../.claude/skills/wireflow/SKILL.md)/
  [`page-brief`](../../.claude/skills/page-brief/SKILL.md) craft.
- Reads the target's existing design system before proposing a new one.

## Canonical outputs

Design-system tokens, `design.md`, the currently configured clickable design artifact, and `spec.md`,
all validated by existing artifact and phase gates.

## Refusal and escalation

- Unframed problem or unresolved job blocking the surface.
- Regenerating an existing design system without authorization.
- Raw visual values where canonical role tokens exist.
- Missing design input hidden as confident direction.
- Attempt to self-certify its own artifact.

## Review topology

For the seat pilot, preserve the current lofi and phase order. A fresh design reviewer judges only
artifacts available at the design gate. Running-code rendered review remains in implementation and
combined verification.

Removing lofi is a separate topology experiment, not a prerequisite for this seat.
